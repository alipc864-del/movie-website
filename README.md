# 🎬 Movie Website

A modern and responsive movie website UI built with HTML, CSS and JavaScript.

## ✨ Features

- 🎬 Featured movie section
- 🔍 Search movies
- ⭐ Movie ratings
- 🏷️ Movie genres
- ▶️ Watch button
- 📱 Responsive design
- ✨ Modern dark UI
- 🎨 Cinematic design

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript

## 🚀 About

This project was created to practice HTML, CSS and JavaScript while building a modern movie website interface.
